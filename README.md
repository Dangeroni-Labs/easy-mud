# Easy Mud

**Easy Mud** is a mod which adds crafting recipe for.. Mud.

## Supported versions

| Minecraft | Forge |
| --- | --- |
| 1.20.1 | **Yes** |

###### Note about versions and mod loaders

I am not planning to add support for other versions or mod loaders rather than **1.20.1** minecraft and **forge** mod loader.

Intentions of this mod were only for myself since I am playing forge 1.20.1 minecraft now.

Nevertheless, it will be available for downloading and I'll be supporting it.
